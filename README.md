# Учебное расписание дня

**Сдал:** Гордеенко А.В.

## Постановка задачи (тема 7)

Реализовать расписание занятий на один день.

**Данные о паре:**
- предмет;
- время начала;
- аудитория.

**Операции:**
1. добавить пару;
2. удалить пару по предмету;
3. найти пару в заданное время;
4. вывести список пар по возрастанию времени.

## Что в репозитории

| Файл | Содержание |

## Запуск

```bash
python structural.py
python oop.py
```

Оба файла запускаются без аргументов и печатают три демонстрационных сценария.

## Стиль решения

**Структурный (`structural.py`)**
- данные: `list` из `dict` вида `{"subject", "start", "time", "room"}`;
- логика: отдельные функции `add_lesson`, `delete_by_subject`, `find_at_time`,
  `sorted_by_time` — оперируют списком, состояние снаружи;
- время дополнительно хранится в минутах от полуночи, чтобы сортировка
  и сравнение работали корректно.

**ООП (`oop.py`)**
- `Lesson` — инкапсулирует поля (`_subject`, `_start`, `_room`), предоставляет
  их только через свойства, валидирует данные при создании;
- `Schedule` — владеет коллекцией и всеми операциями:
  `add`, `remove_by_subject`, `find_by_subject`, `find_at_time`, `sorted_lessons`;
- типовой результат совпадает со структурным вариантом: одни и те же входные
  данные дают одинаковый по смыслу вывод.

## Пример работы

```
=== Пример 1: обычный понедельник ===
добавить 'Математический анализ' 08:30 -> ok
добавить 'Информатика' 10:10 -> ok
добавить 'Физика' 11:50 -> ok
поиск на 10:10 -> Информатика, ауд. 215
поиск на 12:00 -> ничего не найдено
Итоговое расписание:
  08:30  Математический анализ — ауд. 301
  10:10  Информатика — ауд. 215
  11:50  Физика — ауд. 118
```

## Правила (для самопроверки)

- пары выводятся по возрастанию времени начала;
- повторное добавление пары с уже существующим предметом отклоняется;
- удаление по предмету не зависит от регистра;
- поиск по времени точный (`ЧЧ:ММ`, ведущие нули необязательны: `8:30` = `08:30`);
- некорректное время (например `25:99`) отклоняется в ООП-варианте через валидацию.
